# Plan pentru demo (23 oct. 2026, ~16:00)

> **Pentru agenți:** folosiți superpowers:executing-plans (sau subagent-driven-development) task cu task. Pașii au căsuțe (`- [ ]`) ca să bifați progresul.

**Scop:** cele patru momente din design (meeting, conversație, alarmă, „Întreabă meetingul”) merg cap-coadă pe un iPhone real și un laptop, pe hotspot.

**Arhitectură:** aplicația Flutter din `app/` (iPhone + pagina web a prezentatorului) vorbește prin WebSocket și HTTP cu `server/` (Python, FastAPI, în Docker pe laptop). AI-ul (rezumat, simplificare, agentul) rulează pe server prin API-ul Claude.

**Stack:** Flutter 3.41 / Dart, `speech_to_text`, `mobile_scanner`, `qr_flutter`; Python 3.14, FastAPI, `anthropic` 2.1; Docker Compose.

**Design:** `docs/superpowers/specs/2026-10-22-platforma-accesibilitate-design.md`. Reguli: `CLAUDE.md`.

**Meetingul fizic** (vocea speakerului, întrebări, „Ți s-a răspuns”) are plan propriu: `docs/superpowers/plans/2026-10-22-meeting-fizic.md`. El înlocuiește partea de meeting de aici (rolurile din dispozitiv, filtrul de ecou ca mecanism principal).

## Persoana 3: Sunetul vizibil (YAMNet)

**Fișiere:** creați `app/lib/features/alerts/yamnet_detector.dart`, modelul în `app/assets/models/yamnet.tflite` (+ `yamnet_class_map.csv`), schimbați `main.dart` (o linie).

**Interfață de implementat** (`app/lib/features/alerts/sound_alert.dart`):
```dart
class YamnetSoundDetector implements SoundDetector {
  bool get isAvailable;            // true după ce modelul s-a încărcat
  Stream<SoundAlert> get alerts;   // emite SoundAlert(SoundKind.fireAlarm, at: ..., confidence: ...)
  Future<bool> start();            // cere microfonul, pornește fluxul PCM
  Future<void> stop();
  void dispose();
}
```

- [x] `flutter pub add tflite_flutter record`. Microfon: PCM 16 kHz mono (`record`, `startStream`), ferestre de 15.600 eșantioane (0,975 s), conversie la float în [-1, 1].
- [x] Clasele: citiți `display_name` din `yamnet_class_map.csv` și mapați după nume, nu după numere ținute minte: „Fire alarm”, „Smoke detector, smoke alarm” → `fireAlarm`; „Siren”, „Civil defense siren” → `siren`; „Vehicle horn, car horn, honking”, „Air horn, truck horn” → `horn`; „Telephone bell ringing”, „Ringtone” → `phone`; „Doorbell”, „Ding-dong”, „Knock” → `door`.
- [x] Prag: scor ≥ 0,3 în 2 ferestre consecutive. Nu repetați aceeași alertă mai des de o dată la 10 s.
- [x] Teste: maparea claselor și pragul, ca funcții pure (fără model), în `app/test/features/yamnet_mapping_test.dart`.
- [ ] Pe iPhone: alarmă de incendiu de pe YouTube dintr-un difuzor → ecran roșu + vibrație + ieșirea din setări.
- [ ] Pe Mac, în Xcode: Runner → Signing & Capabilities → + „Time Sensitive Notifications”; apoi `cd ios && pod install`.
- [ ] Telefon blocat, ceas la mână: alarma → notificare și vibrație pe ceas.
- Detalii și ce s-a extins (browser, ceas, sunetele locației): `docs/superpowers/specs/2026-10-22-sunetul-vizibil-design.md`.
- [x] `.gitignore` ignoră `*.tflite`; modelul din `app/assets/models/` e deja exceptat ca să ajungă pe Mac.

## Antrenorul de claritate (meeting online): cum se arată

Pe laptopul cu serverul, în Chrome, la `http://localhost:8000` (microfonul și fereastra de deasupra cer https sau localhost):

- [ ] Acasă → „Sunt coleg într-un meeting online” → **Mod demonstrație** (praguri scurte) → „Pornește antrenorul”.
- [ ] „Arată alertele peste meeting”: fereastra mică stă deasupra oricărei aplicații (Teams, Meet, slide-uri).
- [ ] Vorbit fără nicio pauză ~10 s → „Fă pauze între idei”; vorbit foarte repede ~10 s → „Vorbești prea repede pentru subtitrare”; un minut fără pauze lungi → „Ai vorbit un minut fără pauză”; vorbit departe de laptop → „Microfonul te prinde slab”; muzică lângă laptop, cât taci → „Zgomot la tine”.
- [ ] Suprapunerea cere două calculatoare cu același cod de echipă și, pe fiecare, căști sau vocea învățată.
- [ ] Între pași: „Oprește” → „Pornește antrenorul”, ca alertele să pornească de la zero (fereastra de deasupra se redeschide). Alertele apar cu ~1 s întârziere: Echo verifică întâi că e vorbire (YAMNet), ca tastatura și muzica să nu conteze drept vorbit.
- Ritmul se măsoară din silabe și se saturează la vorbire foarte rapidă (`ml/voice/reports/2026-10-23-ritm.md`): la repetiție, verificați alerta de ritm cu persoana care vorbește în demo.

## Zona de risc (de urmărit la repetiții)

1. Recunoașterea vorbirii pe iOS se oprește după ~1 minut; serviciul o repornește automat (`speech_service.dart`). Verificați un monolog de 3 minute.
2. Microfonul iPhone-ului nu poate fi folosit simultan de recunoașterea vorbirii și de YAMNet.
3. Rețeaua: portul 8000 blocat de firewall, IP-ul laptopului schimbat după reconectare la hotspot.
4. Text foarte mare (200%) + mod dislexie pe ecranul participantului: nimic nu trebuie tăiat.
5. Fără internet nu merg nici subtitrarea, nici AI-ul.
6. Antrenorul de claritate pe alt calculator decât cel cu serverul: `http://<ip>:8000` nu e context sigur, deci Chrome nu dă microfonul. Folosiți localhost sau o adresă https.
