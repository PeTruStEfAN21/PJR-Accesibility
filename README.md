# PJR-Accesibility

## Claude Code

Proiectul activează pluginul [Superpowers](https://github.com/obra/superpowers) prin `.claude/settings.json`.
După `git pull`, pornește `claude` în folderul proiectului și acceptă instalarea pluginului când ești întrebat.

Dacă nu apare promptul, instalează manual:

```
/plugin install superpowers@claude-plugins-official
```
